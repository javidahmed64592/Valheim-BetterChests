# Changelog

## 0.1.0

- Initial release.
- Dropped items are stored in nearby chests, preferring chests that already hold the item. They are shown flying into the chest.
- Added a Sort button to the chest panel, which merges stacks and groups items by type.
- The chest panel grows to fit the Sort button and every row of big chests.
- Added keys for take all (`H`), place stacks (`F`) and sort (`G`) while a chest is open.
- Added -/+ buttons and keys (`R`/`T`) to the split stack dialog.
- The keys are shown in the inventory key hints and can be changed in the config file or in game from Settings > Mod Settings.
