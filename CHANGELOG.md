# Changelog

## 0.1.0

- Initial release.
- Dropped items are stored in nearby chests, preferring chests that already hold the item.
- Added a Sort button to the chest panel, which merges stacks and groups items by type.
- Added keys for place stacks (`F`) and sort (`G`) while a chest is open.
- Added -/+ buttons and keys (`R`/`T`) to the split stack dialog.
- The keys are shown in the inventory key hints.
